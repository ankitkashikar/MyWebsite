# 🍜 The Chinese Bliss

A modern and responsive restaurant website for **The Chinese Bliss**, serving authentic Indo-Chinese cuisine in Hinjawadi, Pune.

## 📖 About The Project

The Chinese Bliss website is designed to provide customers with an engaging online experience where they can:

* Browse the restaurant menu
* Learn about the brand and story
* Place online orders
* Make reservations
* Submit bulk and corporate order requests

The project is built using **HTML, CSS, and JavaScript** with a focus on responsiveness, performance, and user experience.

---

## ✨ Features

### 🏠 Home Page

* Hero section with call-to-action buttons
* Restaurant introduction
* Featured food categories
* Order & reservation section
* Social media gallery
* Contact details and opening hours

### 🍽️ Menu Page

* Complete food menu
* Dish descriptions and pricing
* Veg, Vegan, and Spicy indicators
* Responsive card-based layout

### 🛒 Order Page

* Online order form
* Form validation
* User-friendly ordering experience

### 📸 Experiences Page

* Restaurant photo gallery
* Customer testimonials
* Dining experience showcase

### 📦 Bulk Order Page

* Corporate and party order requests
* Catering inquiry form
* Dedicated bulk order contact information

To create a professional digital presence for **The Chinese Bliss** that helps customers discover the restaurant, explore the menu, and place orders seamlessly.
